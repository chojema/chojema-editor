# Chojema Editor

**한국어** | [English](README.en.md)

일반 텍스트, Markdown, HTML을 편집하는 데스크톱 편집기입니다. Markdown과 HTML은 위지위그(보이는 그대로) 방식으로 편집합니다.

## 설치

[Releases](https://github.com/chojema/chojema-editor/releases)에서 운영체제에 맞는 파일을 내려받습니다.

| 운영체제 | 파일 |
|---|---|
| macOS (Apple Silicon, M1 이후) | `Chojema.Editor-<버전>-arm64.dmg` |
| Windows (일반 PC, Intel·AMD) | `Chojema.Editor-Setup-<버전>-x64.exe` |
| Windows (ARM, Snapdragon 노트북 등) | `Chojema.Editor-Setup-<버전>-arm64.exe` |
| Windows (어느 쪽인지 모를 때) | `Chojema.Editor-Setup-<버전>.exe` — 설치할 때 PC에 맞는 쪽을 고름 |

- **macOS**: DMG를 열고 앱을 Applications 폴더로 끌어 넣습니다. 처음 열 때 macOS가 막으면 Finder에서 앱을 Control-클릭 → "열기"를 누르거나, 시스템 설정 → 개인정보 보호 및 보안에서 "확인 없이 열기"를 누릅니다.
- **Windows**: 설치 마법사에서 설치 폴더를 고를 수 있고, 관리자 권한 없이 설치됩니다. "Windows의 PC 보호" 경고가 뜨면 "추가 정보" → "실행"을 누릅니다.
- 설치하면 `.md`, `.markdown`, `.html`, `.htm`, `.txt` 파일을 이 앱으로 열 수 있습니다.

## 기능

| 문서 | 편집 방식 |
|---|---|
| `.txt` 등 | 텍스트 편집 (줄 번호, 찾아 바꾸기, 자동 줄 바꿈) |
| `.md` | 위지위그 편집. 표, 할 일 목록, 수식(LaTeX), Mermaid 다이어그램, 각주, 코드 문법 색상, `/` 명령 메뉴, 문서 속성(frontmatter) 편집 |
| `.html` | 위지위그 편집. 글꼴·크기·색·정렬·첨자, 표, 이미지, 링크, 코드 문법 색상 |

### 보기 방식 (Markdown·HTML)

툴바 오른쪽 버튼이나 단축키로 바꿉니다.

| 보기 | 단축키 | 내용 |
|---|---|---|
| 편집 화면 | `⌘1` | 위지위그 편집만 |
| 나란히 | `⌘2` | 왼쪽 소스, 오른쪽 편집 화면. **양쪽 모두 편집할 수 있고** 잠시 뒤 서로 반영됨. 스크롤도 함께 움직이고, 가운데 경계를 끌어 폭을 조절 |
| 소스 | `⌘3` | 소스 코드만 |

Markdown은 나란히 보기에서 편집 화면을 고쳐도 소스에서는 고친 블록만 바뀌고 나머지 줄은 그대로 유지됩니다.

### 문서 종류 바꾸기

앱을 열면 빈 Markdown 문서가 나옵니다. 상태 표시줄 왼쪽의 문서 종류(**Markdown ▾**)를 누르거나 파일 메뉴의 "새 텍스트 문서"(`⌘N`)·"새 Markdown 문서"(`⇧⌘N`)·"새 HTML 문서"(`⌥⌘N`)를 고르면 됩니다. 아직 아무것도 쓰지 않은 빈 창은 그 자리에서 바뀌고, 내용이 있거나 저장된 문서라면 새 창이 열립니다.

### 그 밖의 기능

- **개요** (`⇧⌘O`): 제목 목록을 보고 눌러서 이동
- **찾기·바꾸기** (`⌘F`, `⌥⌘F`): 대소문자 구분, 하나씩 바꾸기, 모두 바꾸기
- **PDF로 내보내기** (파일 메뉴, `⇧⌘E`)와 **인쇄** (파일 메뉴, `⌘P`)
- **내보내기** (파일 → 내보내기): HTML로 저장(이미지 포함 한 파일), 서식 있는 텍스트로 복사(메일·블로그 붙여넣기용)
- **옛 한글 문서**: EUC-KR(CP949)·UTF-16 파일을 알아서 읽고, 상태 표시줄에 인코딩과 줄바꿈 방식(LF/CRLF)을 표시. 저장은 UTF-8로 하며 처음 저장할 때 확인
- **끌어다 놓기**: `.md`·`.html`·`.txt` 파일을 창에 놓으면 열림
- **글자 크기**: 상태 표시줄 오른쪽 **− 100% +** 버튼 (`⌘−` / `⌘=`, `⌘0`은 원래 크기). 텍스트 문서, 편집 화면, 소스 화면 모두에 적용
- **선택 시 복사**: 상태 표시줄의 **선택 시 복사** 버튼이나 편집 → "선택하면 바로 복사"로 켜고 끔. 켜면 글자를 선택하는 즉시 클립보드에 복사되고 "✓ 복사됨"이 잠깐 표시됨. 편집 화면에서는 서식까지 함께 복사
- **링크** (`⌘K`), **테마** (보기 → 테마: 시스템/밝게/어둡게)

### 원본 보존 방식

- **Markdown**: 고치지 않은 블록은 디스크에 있던 글자 그대로 저장합니다. 문서를 열었다가 그대로 저장하면 파일이 바이트 단위로 같습니다. 앞머리(frontmatter), 줄바꿈 방식(CRLF), BOM도 유지합니다.
- **HTML**: `<body>` 안쪽만 편집하고 `<head>`와 `<body>` 태그는 원문 그대로 둡니다. 문서의 CSS를 편집 화면에 적용해 브라우저에서 보는 모습으로 편집합니다. class·id·style·data-* 속성, `<div>`/`<section>` 같은 레이아웃 요소는 유지됩니다. `<script>`, `<iframe>`, `<form>`, SVG처럼 화면에서 직접 고칠 수 없는 요소는 원래 코드를 그대로 보존하고, 두 번 클릭하면 코드를 고칠 수 있습니다.

### HTML 편집의 한계

- HTML 주석(`<!-- -->`)은 저장할 때 사라집니다.
- 내용을 고친 뒤 저장하면 본문 블록이 한 줄씩 정리되고, 일부 CSS 값 표기가 바뀔 수 있습니다(예: `#d33` → `rgb(221, 51, 51)`). 아무것도 고치지 않았다면 원문 그대로 저장합니다.
- 표 열 너비를 마우스로 조절할 수 없습니다.
